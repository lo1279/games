# 《三国志·群英塔防》(Three Kingdoms Tower Defense)

> **国风写意 · 名将争锋 · 兵种克制 · 极致战术**  
> 基于 **React 19 + TypeScript + HTML5 Canvas + Tailwind CSS + Vite** 构建的现代化三国题材塔防独立游戏。

---

## 🌟 游戏核心机制与特色系统

### 1. 兵种克制与战术连携 (Tactical Synergy & Combo)
战场引入深度的战斗克制与伤害属性模型，拒绝纯数值碾压，讲求排兵布阵与武将连携：
- **三种伤害属性与克制克减**：
  - **挥砍斩击 (Slash)**：关羽、张飞、赵云等近战名将，克制步兵与盾兵（**+30% 增伤**）；
  - **穿刺破空 (Pierce)**：黄忠、孙尚香等神射弓将，克制轻骑兵与突袭刺客（**+35% 增伤**）；
  - **奇门奇策 (Magic)**：诸葛亮、周瑜、华佗等法系谋士，克制铁壁重甲与攻城器械（**无视大量护甲，+40% 增伤**）。
- **名将 Combo 连携**：
  - **诸葛亮【感电】+ 物理输出**：敌方处于雷击感电期间，受到关羽/张飞/赵云/黄忠物理伤害**必定暴击 (1.5倍)** 并迸发雷芒电弧；
  - **周瑜【火海】+ 顺劈/连刺**：周瑜烈焰火海附带 **50% 熔甲破防** 效果；
  - **关羽【青龙斩】削弱**：命中目标额外削减 **35% 护甲**；
  - **曹操【枭雄霸业】增伤与掠夺**：未休整的曹操为周围 180 码友军提供 **+20% 增伤光环**，且受庇护名将击杀敌人可**额外掠夺 2 军饷**。

### 3. 三大关卡地形与专属史诗 Boss 机制

#### ① 第一回：曲阳平乱 (黄土荒原)
- **地形路线**：**双 U 型回龙盘旋路线**（马蹄回环），形成上下交错的两片火力交叉打击区。
- **关底 Boss · 天公将军 张角**：
  - **死士召唤**：定时呼唤黄巾死士护卫突围；
  - **天公雷罚**：进入 2.0s 蓄力吟唱（头顶浮现黄色蓄力进度条），引导五雷轰顶全场，**可用张飞当阳吼或华佗麻沸散打断**。

#### ② 第二回：虎牢雄关 (青石要塞)
- **地形路线**：**S 形三折天堑迂回关隘**，敌军自西北营门三道曲折杀入东南关城。
- **关底 Boss · 关西猛将 华雄**：
  - **名将力竭**：普通攻击挥砍震慑，命中的防御名将会陷入 **1.5s 力竭休整**；
  - **铁壁狂暴**：血量降至 50% 时激活 **2500 点金色铁壁护盾**并触发狂暴，大幅提升移速，必须集中火力破盾。

#### ③ 第三回：决战下邳 (白门水泽)
- **地形路线**：**外城护城河螺旋包围深入中军白门楼**，极度考验单兵长距离火力调遣。
- **关底 Boss · 战神 吕布 (天下无双)**：
  - **阶段一 (辕门穿云射)**：蓄力 1.5s 瞄准全场攻击力最高的名将释放贯穿穿云箭，将其击退或打入休整；
  - **阶段二 (魔神降世)**：半血狂暴进入二阶段，地面浮现 **190 码暗红预警圈**蓄力扫荡，玩家需通过**战术阵位调遣移驻**或**强控打断**进行规避！

### 4. 战术阵位调遣与视野防遮挡体验
- **阵位调遣令 (-25 军饷)**：
  - 战斗中支持随时选中名将，点击【调遣】平移至战场任意空闲平地，灵活根据出兵路线和 Boss 突围策略变换阵型。
- **全屏视野防遮挡优化**：
  - 调遣选点与战法瞄准定点施法期间，底部武将面板**自动隐去**，顶部居中浮现专属操作提示栏（带取消按钮），战场 100% 无死角呈现。
- **冷却展示规范化**：
  - 战法卡片右上角显示**基准冷却周期**（如 `基准冷却: 7s`），施法按钮独占显示**动态跳秒倒计时**，信息分工明确消除视觉重复。

### 5. 移动端 (手机 / 微信 / 平板) 全适配增强
- **触控精度提升 60%**：
  - 移动端触控判定半径扩增至 **42 逻辑像素**，搭配**距离最近吸附算法**，手指粗大也能轻点即中。
- **点将台一键折叠抽屉**：
  - 手机竖屏时支持「收起战场 / 展开将台」，选中布阵英雄时自动折叠最小化，完全释放战场可视范围。
- **现代视口标准**：
  - 采用 `100dvh` 与安全区（Safe-Area Insets），杜绝 iOS Safari / 微信地址栏弹性跳动与齐刘海遮挡；
  - 全局拦截长按系统放大镜、保存图片与双指缩放手势。
- **横竖屏智能指引与全屏沉浸**：
  - 手机竖屏检测并友好提示「建议横屏体验全景古战场」；
  - TopBar 支持一键 **Fullscreen 全屏沉浸模式**，小屏按键紧凑布局不换行。

## 🛠️ 技术栈与架构设计

- **核心框架**：React 19, TypeScript
- **构建工具**：Vite 8
- **样式与动画**：Tailwind CSS v4 + 现代古风主题调色盘
- **图形渲染**：HTML5 Canvas 2D，纯原生 60FPS 双缓冲游戏循环与粒子系统
- **音频引擎**：Web Audio API 纯数学程序化即时音效合成（战鼓、号角、烈火、雷鸣、刀剑入肉、金币）
- **图标系统**：Lucide React

## 🚀 本地运行与部署

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
启动成功后访问 `http://localhost:5888`（或终端输出的对应端口）。

### 3. 全量构建验证 (TypeScript 编译 + 静态打包)
```bash
npm run build
```
打包产物位于 `dist/` 目录，可直接部署于 Nginx、GitHub Pages、Vercel 或任意静态托管服务器。

### 4. 生产预览
```bash
npm run preview
```

## 🎮 操作快捷键与手势指引

- **鼠标左键 / 单指轻点**：
  - 点击点将台武将进入布阵；
  - 点击战场名将查看面板、升级晋升或指派战法；
  - 调遣或手操瞄准时，点击地面确定落点。
- **鼠标右键 / 悬浮栏取消按钮**：
  - 取消当前正在进行的布阵、调遣或战法瞄准。
- **战法模式切换**：
  - 点击底部「自动 / 手操」可在“满怒自动施法”与“主公手动定点轰炸”间自由切换。
- **移动端手机横屏**：
  - 将手机旋转至横屏，享受 16:9 全景视界与最大战场覆盖率。
