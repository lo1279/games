# 三国志·群英塔防 (Three Kingdoms Tower Defense)

经典国风三国题材塔防独立游戏，基于 React 19 + TypeScript + HTML5 Canvas + Tailwind CSS 打造。

---

## 游戏核心特色

1. **三国名将防御阵列**：
   - **关羽**（武圣）：青龙偃月刀范围顺劈，战法【青龙斩】削减敌阵护甲。
   - **张飞**（万人敌）：丈八蛇矛强击退，战法【当阳怒吼】范围大震慑眩晕。
   - **赵云**（龙胆）：常山白马银枪，极速连刺突杀突破先锋。
   - **黄忠**（神射）：老当益壮，全场超远射程狙杀，暴击致命。
   - **诸葛亮**（卧龙）：八卦天雷阵，链式闪电弹射并施加强力减速。
   - **周瑜**（美周郎）：赤壁烈火火球，地面灼烧持续持续伤害（DoT）。
   - **曹操**（魏武）：枭雄光环与战法【短歌行】，提升周围武将伤害并激励全军攻速。
   - **孙尚香**（枭姬）：散射穿透飞矢，密集压制群敌。

2. **三路历史战役关卡**：
   - **第一回：曲阳平乱**（剿灭黄巾·荡平贼寇，迎战天公将军张角）
   - **第二回：虎牢雄关**（力破西凉铁骑与冲阵攻城车，力战关西猛将华雄）
   - **第三回：决战下邳**（水路并进险恶地形，决战天下无双战神吕布）

3. **主公锦囊计策**：
   - **借东风**：全场冰封定身所有进犯敌军 3.5 秒。
   - **火烧连营**：全屏烈焰天罚轰炸敌军全阵。

4. **即时程序化战场音效**：
   - 采用 Web Audio API 进行纯算法音频合成（战鼓、弓箭、斩击、雷鸣、烈焰、金币入账等），零外部媒体依赖，开箱即响，支持一键静音。

## 本地运行指南

### 1. 开发模式运行（热更新 HMR）
在项目目录下执行：
```bash
npm run dev
```
然后在浏览器中打开终端显示的本地地址（通常为 `http://localhost:5173/`）。

### 2. 生产预览
```bash
npm run build
npm run preview
```

## 游戏操作指南
- **招募与布防**：在右侧「主公点将台」点击心仪武将，随后在战场棋盘的「点将台」上点击即可完成驻防。
- **名将晋升**：在战场中点击已驻防武将，可在左下方卡片查看其攻击力、射程、斩杀数与输出战绩，并可消耗军饷进行晋升升星（最高5星·破界觉醒）或撤阵返还军饷。
- **迎击敌军**：布置好阵型后，点击右下方「擂鼓迎击」开始发兵。
- **倍速与暂停**：顶部支持 1x/2x 倍速与随时战术暂停。
