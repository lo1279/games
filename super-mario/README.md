# 🍄 超级马里奥兄弟 (Super Mario Bros FC)

高保真还原任天堂 1985 年红白机（NES / FC）经典平台跳跃游戏《超级马里奥兄弟》World 1-1 关卡。
基于原生 HTML5 Canvas 2D 像素引擎与 Web Audio API 程序化音效合成，零外部资源依赖，秒级加载，畅快游玩。

---

## 🕹️ 游戏特色

1. **经典物理与手感**：
   - 真实加速度、最高奔跑速度（冲刺与普通）、地面摩擦力。
   - 动态跳跃高度控制：轻按小跳，长按大跳；奔跑冲刺起跳获得更远的飞跃距离。
   - 转向滑行急刹车与经典音效反馈。

2. **完整 World 1-1 关卡体验**：
   - 地面砖、隐藏金币砖、可破坏红砖（大马里奥可击碎并四散飞溅）、问号砖。
   - 经典绿水管、深渊断崖裂谷、终点金字塔阶梯。
   - 终点胜利旗杆下滑动画与步入城堡过关判定。

3. **敌人与道具机制**：
   - **Goomba（板栗仔）**：地面巡逻，踩踏压瘪，触碰致伤。
   - **Koopa（绿乌龟）**：巡逻，踩踏缩壳；再次触碰踢飞高速滑行，滑行龟壳可击溃沿途怪物。
   - **超级红蘑菇**：从问号砖缓缓钻出，落地向右滑行，拾取后变身超级大马里奥。
   - **金币**：顶出金币旋转动画并加分。

4. **Web Audio 纯原生程序化 8-Bit 音效**：
   - 跳跃音、顶砖撞击音、碎砖爆炸音、金币双音阶、踩怪踏击音、变身琶音、死亡旋律与通关胜利号角，原生实时合成，无需担心外部音频 404。

5. **复古 CRT 显像管滤镜与全屏**：
   - 支持一键切换 CRT 扫描线光栅滤镜，重温童年电视机复古质感。

## 🎮 操作说明

### 桌面端键盘控制
| 功能 | 快捷键 |
| :--- | :--- |
| **左右移动** | `A` / `D` 或 `←` / `→` |
| **下蹲** | `S` 或 `↓` (限大马里奥形态) |
| **跳跃** | `K` / `Z` / `空格键` (长按跳得更高) |
| **冲刺奔跑** | `J` / `X` / `Shift` |
| **暂停 / 继续** | `P` |
| **重新开始** | `R` 或 `Enter` |

### 移动端触屏控制
- 屏幕下方提供专有 **D-Pad 方向键**（左、右、下）。
- 右侧提供经典 **B 奔跑加速键** 与 **A 跳跃键**。

---

## 🚀 技术栈
- 渲染层：HTML5 Canvas 2D (256x240 原生 NES 分辨率，保持像素清晰度)
- 音效层：Web Audio API (方波 / 三角波 / 白噪音实时震荡器合成)
- 架构：独立模块化设计 (`audio.js`, `constants.js`, `tilemap.js`, `entities.js`, `game.js`, `touch.js`)
