# 经典与现代双主题扫雷 (Minesweeper)

一款基于纯原生前端技术栈（HTML5 + CSS3 + ES6 JavaScript）构建的高质量独立网页版扫雷游戏。

## ✨ 特性亮点

- **首击必安全保障 (Safe First Click)**：首次点击动态生成雷区，确保首次左键点击绝不会踩雷，且必定触发大片空白连锁展开。
- **经典操作完整还原**：
  - **左键点击**：翻开未知方块。
  - **右键点击 / 移动端长按**：循环切换标记「🚩 旗帜 ➔ ❓ 疑问 ➔ 清除标记」。
  - **双击 / 左右键同按 (Chording)**：在已翻开的数字格上快速自动翻开周边未标记方格。
- **双主题视觉系统**：
  - **现代暗夜毛玻璃 (Cyber Dark)**：微光悬浮质感、细腻动效与高对比度霓虹标识。
  - **经典 Win98 复古拟物 (Classic Retro)**：经典 3D 浮雕灰白外框、Windows 标题栏与原汁原味的怀旧手感。
- **纯代码原生音效合成 (Web Audio API)**：
  - 运用浏览器底层音频振荡器与白噪声合成点击、插旗、拔旗、踩雷爆炸与胜利欢庆音效，无需外部音频资源，离线可玩且永不丢失资源。
- **状态仪表盘 & 历史战绩**：
  - 七段数码管（LED）风格的剩余地雷计数与计时器。
  - 随交互动态变化的经典表情（😊正常 / 😮紧张 / 😵踩雷 / 😎通关）。
  - 各难度等级的本地通关最佳纪录保存（`localStorage`）。

## 🎮 难度模式

- **初级 (Beginner)**：9 × 9 网格，10 颗地雷
- **中级 (Intermediate)**：16 × 16 网格，40 颗地雷
- **高级 (Expert)**：30 × 16 网格，99 颗地雷
- **自定义 (Custom)**：自由配置行数、列数及地雷总数

## 🚀 启动与体验方法

直接在任意现代浏览器（Chrome、Edge、Firefox 等）中**双击打开 `index.html`** 即可畅玩，无需安装 Node.js 或启动任何本地开发服务器。
