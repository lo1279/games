# 经典与现代双主题扫雷 (Minesweeper)

一款基于纯原生前端技术栈（HTML5 + CSS3 + ES6 JavaScript）构建的高质量跨端扫雷游戏。既支持 PC 浏览器桌面键鼠经典操作，又针对手机端与移动浏览器进行了深度的人机交互调优与兼容性增强；同时包含完整的原生微信小程序工程。

---

## ✨ 核心特性亮点

### 1. 🧠 严谨算法与开局避险保障
- **动态避险区算法 (Safe First Click)**：首次点击动态生成雷区，确保首点必定安全。算法会根据首点所在的中心（9格）、边缘（6格）或角落（4格）动态匹配实际邻居数，即使在高密度自定义模式下也不会误降级，必触发开阔的空白连锁展开（Flood Fill）。
- **失败结算可视化精准溯源**：
  - 💥 **触发引爆点**：红底脉冲动画标明踩雷坐标；
  - 💣 **未排除地雷**：清晰展现其余全部真雷位置；
  - ❌ **误标错旗识别**：标出玩家插错旗的非雷格子，杜绝“数字与周围雷数不符”的视觉误解。

### 2. 📱 手机端体验与深度兼容性增强 (Mobile Friendly)
- **全面屏安全区适配 (Safe Area Inset)**：
  - 适配 iPhone 与主流 Android 全屏手机的顶部状态栏与底部手势横条（Home Indicator），底部操作栏永不被遮挡。
- **大拇指舒适触控方格 (Thumb-friendly Sizing)**：
  - 针对手机端视口动态注入难度适配类。初级模式（9×9）在手机端自动将方格由 30px 放大至 36px，单手大拇指触控舒适不误触。
- **双模操作切换与长按防抖保护**：
  - 底部专属 **「⛏️ 挖掘模式 / 🚩 插旗模式」** 快速切换，单手一键连插多旗；
  - 支持手机长按 350ms 插旗/拔旗，具备防合成 Click 拦截机制，彻底消除长按抬手后误挖开的痛点。
- **移动端丝滑滚动与触觉反馈 (Haptic Feedback)**：
  - 棋盘容器内嵌 `-webkit-overflow-scrolling: touch` 与 `overscroll-behavior: contain`，查看大棋盘平滑阻尼不带跑整个页面；
  - 支持 Web Vibration API，插旗轻震（30ms）、踩雷重度震颤（双震）与胜利通关欢庆震动。

### 3. 🖥️ PC 桌面端经典操作全支持
- **左键单开**：翻开未知方格。
- **右键 / 中键**：循环标记「🚩 旗帜 ➔ ❓ 问号 ➔ 清除标记」。
- **双键和弦展开 (Chording)**：
  - 鼠标左右键同时按下（或双击数字格、滚轮中键），周围插旗数达标时自动翻开周边未标格，带双键防残留连击优化。

### 4. 🎨 双主题视觉风格
- **✨ 现代暗夜毛玻璃 (Modern Cyber Glass)**：
  - 霓虹数字、细腻磨砂毛玻璃面板、胜利炫彩五彩纸屑粒子烟花特效。
- **🎨 经典 Win98 复古拟物 (Classic Win98 Retro)**：
  - 经典蓝绿桌面背景、3D 凸起/凹陷浮雕灰白外框、经典像素字体与笑脸按钮。

### 5. 🔊 纯原生代码音频合成 (Web Audio API)
- 无需加载任何外部 mp3/wav 资源，纯原生振荡器与白噪声实时合成清脆点击声、机械插旗声、和弦轻鸣、炸弹沉浸爆炸声与通关琶音。开箱即玩，离线永不丢声。

## 🎮 难度模式预设

| 难度 | 棋盘规格 (列 × 行) | 地雷总数 | 适合设备与场景 |
| :--- | :---: | :---: | :--- |
| **初级 (Beginner)** | 9 × 9 | 10 雷 | 手机单手速通、新手入门 |
| **中级 (Intermediate)** | 16 × 16 | 40 雷 | 经典进阶，平衡挑战 |
| **高级 (Expert)** | 30 × 16 | 99 雷 | 桌面大屏挑战，像素级网格防折行 |
| **自定义 (Custom)** | 8~40 列，8~30 行 | 自由配置 | 极限雷密度、个性化训练 |

## 🚀 启动与体验方式

### 🌐 网页端 (PC / 手机浏览器)
- **直接双击运行**：在本地文件夹中直接双击 `index.html` 即可在 Chrome、Edge、Safari 或手机浏览器中畅玩，无需安装 Node.js 或启动后端服务器。
- **本地服务体验（可选）**：通过任何静态服务器（如 VSCode Live Server、`python -m http.server 8080`）亦可顺畅访问。

### 📱 微信小程序端
- 启动 **微信开发者工具**；
- 选择 **“导入项目”**，目录选择 `D:\ai项目\games\minesweeper\miniprogram`；
- 使用测试号或自有 AppID 编译，即可在模拟器或真机预览中畅享原生小程序版本。
