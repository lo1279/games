# 扫雷微信小程序部署与运行指南

本项目为原生微信小程序工程，专门针对**手机触屏手势**与**单手操作习惯**进行了深度定制。

## 📱 手机端专属特性

1. **底部双模切换开关 (挖掘 ⛏️ / 插旗 🚩)**：
   - 解决手机端没有鼠标右键的痛点。切换为「插旗模式」后，轻触即可秒速标记多个地雷；「挖掘模式」下单触翻开，触击数字格自动和弦（Chord）展开。
2. **长按双轨支持**：
   - 无论在何种模式下，长按任意方块（300ms）均可快速标记/拔除旗帜，伴随轻微马达震动。
3. **原生级平移与双指缩放 (Pinch-to-Zoom)**：
   - 基于原生 `<movable-view>` 组件构建，初级、中级（16×16）、高级（30×16）均可任意无级双指缩放拖动，大棋盘不误触。
4. **真实触觉反馈 (Haptic Feedback)**：
   - 调用 `wx.vibrateShort` 与 `wx.vibrateLong`，提供点击、插旗、踩雷爆炸与胜利结算的层级式震动反馈。
5. **全面屏与安全区适配**：
   - 自动适配 iPhone 底部手势横条与状态栏安全区。

## 🚀 微信开发者工具运行步骤

1. **下载开发者工具**：
   - 前往微信官方网站下载并安装 [微信开发者工具 (WeChat DevTools)](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. **导入项目**：
   - 打开微信开发者工具，在项目列表中点击 **“导入 (Import)”**。
   - **项目名称**：扫雷
   - **目录**：选择本项目目录 `D:\ai项目\games\minesweeper\miniprogram`
   - **AppID**：可填写您自己的小程序 AppID，或者选择 **“测试号 (使用测试号)”**。
   - **开发模式**：选择 **小程序**。
3. **预览与真机调试**：
   - 点击工具栏的 **“编译”** 按钮即可在模拟器中即刻体验。
   - 点击 **“真机调试”** 或 **“预览”**，使用微信扫描二维码，即可在手机微信中实时畅玩！
4. **上传审核**：
   - 登录您自己的微信小程序后台并配置 AppID 后，点击右上角 **“上传”** 按钮，即可在微信小程序管理后台提交审核并正式发布上线。
