# 🎲 3D 骰王争霸 (Dice Master 3D)

一款兼具**次世代 3D 物理渲染交互**与**四合一趣味玩法**的现代化骰子游戏。纯原生 Web 前端架构打造，零环境编译依赖，双击即玩，并深度兼容手机竖屏、微信小程序 `<web-view>` 与各类移动端浏览器。

---

## 🌟 核心特色与技术亮点

### 1. 物理级 3D 渲染引擎 (Three.js 真实感定制)
- **圆角长方体倒角 (`createRoundedBoxGeometry`)**：自研细分投影算法，告别 90° 生硬纸盒直角，呈现真实象牙骰子的顺滑圆弧倒角高光。
- **次表面物理清漆材质 (`MeshPhysicalMaterial`)**：具备 **96% Clearcoat 透明清漆保护层**与 0.16 象牙树脂质感，光线掠过边缘流淌出镜面流动高光。
- **凹陷雕刻法线贴图 (`Indented Pips & Bump Map`)**：512×512 高清绘制打孔倒角光圈、孔内下陷阴影与瓷釉填漆质感（1点中国朱砂红、其余深曜黑蓝），光照下凹槽立体阴影清晰可见。
- **影棚级环境反射 (`Studio HDRI`)**：纯程序化动态生成 360° Studio 全景贴图（`scene.environment`），骰子在翻滚时每一面与倒角均能倒映柔光箱流动光带。
- **动力学刚体弹跳与微颤 (`Settling Wobble`)**：3 段真实重力加速度能量衰减弹跳，平滑吸附目标点数，并在触地静止前呈现真实阻尼谐振微摇晃（Damped Oscillation）。
- **3D 骰盅动画体系**：支持骰盅平滑盖下、震动摇晃、**交互式半掀开偷瞄 (Peek)** 与升起开盅动画，无任何瞬移与画面穿模。

### 2. 纯程序化物理音效与触感震动 (Web Audio API & Haptics)
- **纯程序化音频合成**：无需加载任何外部 mp3/wav 资源，秒开即响且 100% 可用。
- **动能自适应撞击声**：结合下落瞬时撞击速度，触地瞬间触发低频木质空腔共振与高频坚硬敲击复合音。
- **真机触感振动反馈 (`Haptic Feedback`)**：摇骰时微弱震颤、落地坚硬短顿挫、大奖获胜强劲节奏震动（不支持设备与首次手势前安全降级）。

### 3. 手机端与微信小程序全方位深度兼容
- **防橡皮筋下拉黑底**：注入 `overscroll-behavior-y: none;`，消除微信上下滑动时触发的“网页由微信提供”下拉灰底。
- **画布手势隔离**：3D 托盘视口隔离 `touch-action: none;`，杜绝画布手势与页面滚动冲突。
- **WebGL 切后台保护与节电**：监听 `webglcontextlost` 与 `visibilitychange`，切出微信或锁屏时自动休眠暂停渲染，**不发热、省电量**；切回时无缝恢复，**绝不黑屏崩溃**。
- **动态 DPR 控制**：精准限幅 `pixelRatio <= 1.75`，在保证超高清视网膜显示的同时减轻 50% 移动 GPU 运算负载。
- **小屏自适应与大触控吸底栏**：自动避让 iPhone 底部横条安全区（`safe-pb`），大拇指黄金热区单手操作自如。

## 🎮 四合一玩法体系

| 玩法模式 | 规则简介 | 特色机制 |
| :--- | :--- | :--- |
| 🎯 **骰宝押大小 (Sic Bo)** | 3 颗骰子摇盅。大 (11-17)、小 (4-10)、单/双、指定总点数 (4~17)、全围豹子 (1:24 高赔率)。 | 围骰（豹子）庄家通吃大小与单双；配备开奖走势路单与连胜统计。 |
| 🗣️ **吹牛大话骰 (Liar's Dice)** | 玩家 vs 智能心理 AI，各持 5 颗暗骰，轮流叫出全场点数总数量。 | 1 点在叫出前为万能点；支持跳斋；支持 **👀 3D 偷瞄骰盅**；AI 具备概率推断与心理诈唬。 |
| ⛵ **快艇骰子 (Yahtzee)** | 5 颗骰子每轮可重掷最多 3 次，可点击任意锁定保留骰子。 | 13 项组合计分表（葫芦、大顺、小顺、快艇等）；上半区满 63 分额外奖 35 分红利。 |
| 🎲 **自由随心掷骰 (Free Roll)** | 1~6 颗骰子随心投掷，总和、极值分析。 | 聚会、决议、桌游、抽奖通用利器；全同点数触发幸运豹子彩蛋。 |

## 🚀 启动与运行

本游戏为纯静态 Web 架构，支持以下方式启动：

### 方式 1：双击直接运行 (最快捷)
直接在 Windows 文件资源管理器中进入目录，双击 `index.html` 即可在任意现代浏览器（Chrome、Edge、Safari 等）中畅玩。

### 方式 2：使用本地静态服务器
```bash
# 进入目录
cd D:\ai项目\games\dice-game

# 使用 Python 启动
python -m http.server 8080

# 或使用 Node.js / npx
npx serve .
```
浏览器打开 `http://localhost:8080` 即可在局域网内用手机扫码体验。

### 方式 3：部署到微信小程序
请参阅专属部署集成指南：[wechat-miniprogram-deployment.md](file:///D:/ai项目/games/dice-game/wechat-miniprogram-deployment.md)。
