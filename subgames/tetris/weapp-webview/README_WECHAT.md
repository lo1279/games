# 📱 俄罗斯方块微信小程序部署与使用指南

本目录（`weapp-webview/`）是专门为**微信小程序**量身定制的完整工程模板，内部基于微信官方 `<web-view>` 组件实现全屏沉浸式无缝内嵌。

---

## 🚀 极速上手：三步快速运行与预览

### 第一步：将游戏 H5 资源部署到服务器
将 `D:\ai项目\games\tetris\` 根目录下的静态资源（`index.html`、`style.css`、`game.bundle.js`）上传至任意支持 HTTPS 的静态托管服务：
- **免费推荐 1**：Vercel、Cloudflare Pages、GitHub Pages（海外访问极快，零成本，免备案）。
- **国内推荐 2**：腾讯云开发 (CloudBase) 静态网站托管、阿里云 OSS、华为云 OBS。
- **本地局域网调试**：也可以使用本地运行静态服务（如 `npx serve .` 或 Live Server），配合内网穿透（如 cpolar / ngrok）生成临时 HTTPS 网址。

---

### 第二步：配置小程序链接
打开 `weapp-webview/pages/index/index.js`，将 `gameUrl` 替换为您的线上 HTTPS 网页地址：

```javascript
Page({
  data: {
    // 替换为您的实际部署地址：
    gameUrl: 'https://your-domain.com/tetris/index.html'
  },
  // ...
});
```

---

### 第三步：使用微信开发者工具打开与调试
1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开微信开发者工具，点击 **“导入项目”**：
   - **目录**：选择当前目录 `D:\ai项目\games\tetris\weapp-webview\`。
   - **AppID**：可填写您注册的小程序 AppID，也可以先选择 **“测试号”**（无需注册即可体验）。
3. **本地开发调试关键设置**：
   - 在微信开发者工具右上角点击 **“详情”** -> 切换到 **“本地设置”**。
   - **务必勾选**：`不校验合法域名、web-view (业务域名)、TLS版本以及HTTPS证书`。
   - 点击编译，即可在模拟器中即时畅玩！
4. 点击工具栏的 **“预览”** 按钮，用手机微信扫码即可在真机上操作游玩！

## 🌐 正式发布上线指引 (生产环境)

当您准备正式向所有微信用户发布上线时，请按照微信官方规范配置业务域名：

1. 登录 [微信公众平台 (mp.weixin.qq.com)](https://mp.weixin.qq.com/)。
2. 进入：**开发管理** -> **开发设置** -> **业务域名**。
3. 点击“修改”或“添加”：
   - 下载微信提供的校验文件（例如 `xxxx.txt`），上传到您网站根目录下。
   - 填写您的域名（必须为备案过的 HTTPS 域名，例如 `https://your-domain.com`）。
   - 点击“保存”，完成域名合法性认证。
4. 在微信开发者工具中点击 **“上传”** 按钮，提交审核即可！
