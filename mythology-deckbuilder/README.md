# 《万神纪元：诸神对决》（Pantheon: Clash of Myths）

一款融合**华夏神话**、**希腊神话**与**北欧神话**的深度 **Roguelike 卡牌构筑（Deckbuilder）独立游戏**。  
专为**移动端手机竖屏**与**微信小程序环境**量身打造，支持单手触屏操作、原生触觉震颤反馈（Haptic）、防抖吸附滑动、全套牌强化熔炉、战术仙丹法宝与多幕史诗战役。

---

### 2. 卡牌淬火与强化锻造系统 (Card Upgrade System)
* **全卡库支持强化（`+` 阶）**：所有卡牌均可在神术熔炉中进行灵力淬火，数值全面跃升（伤害/护盾提高 35%~50%，异常层数增加，附加特殊特效）；
* **强化卡牌尊享金色动效**：卡牌拥有专属金色脉冲角标 `+`，属性词条高亮显示；
* **三大强化获取途径**：
  * **诸神圣火营地**：新增【淬炼神术】选项，免金币任选牌库中 1 张卡牌强化；
  * **诸神黑市**：商会提供【诸神铁砧】付费强化服务；
  * **神坛奇遇事件**：特定神话奇遇可触发神术顿悟。

---

### 3. 战术仙丹法宝系统 (Tactical Potions)
* **双槽位即时快捷法宝**：在战斗界面顶部常驻 2 个仙丹插槽，关键时刻扭转战局；
* **神话法宝品类**：
  * 💊 **九转金丹**：太上老君金炉神丹，立即恢复 25 点生命并获得 1 点力量；
  * 🏺 **奥林匹斯仙露**：立即恢复 2 点神力并抽 2 张牌；
  * 🍺 **狂战士神蜜酒**：本场战斗永久增加 3 点力量；
  * 🛡️ **金刚护体神液**：立即获得 20 点坚韧护盾；
  * ⚡ **雷暴天露**：造成 15 点全场雷暴伤害并施加 2 层破甲；
  * 🔥 **三昧真火灵油**：引动天地业火，给敌方全体施加 5 层灼烧。
* **掉落与获取**：战斗胜利有概率拾取，亦可在黑市商会直接购买。

## 📱 移动端与微信小程序专属深度优化 (Mobile & WeChat Special)

1. **防橡皮筋下拉抖动与黑底保护**：
   * 采用 `overscroll-behavior-y: none;`，彻底杜绝微信内上下拖动导致露出“网页由 xxx 提供”灰色背景与回弹抖动；
   * 采用 `-webkit-overflow-scrolling: touch;`，保持全手势丝滑原生惯性。
2. **触觉震颤打击反馈系统 (Haptic Engine)**：
   * 原生接入 `navigator.vibrate`：普通攻击短震（20ms）、防御格挡轻震（10ms）、全屏雷暴/终极打击连环脉冲震（[25, 30, 40]ms），大幅增强触屏打击实体感。
3. **英雄选择页水平吸附滑动 (CSS Scroll Snap)**：
   * 支持 `snap-x-mandatory` 与 `snap-center`，左右滑动神明卡牌自动居中吸附；
   * 配备 5 个自适应翻页圆点指示器（Pagination Dots），选定状态光点自动同步跟随；
   * 紧凑自适应高度排版，在 375px~430px 全系手机上一屏完全呈现，无需上下滚动。
4. **上下纵向对决布局与安全区**：
   * 顶部避让微信胶囊按钮（`safe-area-inset-top`），中场血条与法宝插槽，底部触屏手牌；
   * 手牌区横向平滑吸附排布，支持超窄屏自动紧凑排列。
5. **点选预览 + 快捷确认出牌**：
   * 单击手牌浮起大字预览，提供醒目的【▶ 打出】确认按钮，神力不足置灰提示，杜绝小屏误触。
6. **首触 Web Audio API 解锁**：
   * 自动监听全局首次触摸手势激活音频上下文，纯代码实时振荡生成打击、圣盾、雷暴、号角音效，零 MP3 外部网络加载，微信内秒开即玩。
