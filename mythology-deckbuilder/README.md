# 《万神纪元：诸神对决》（Pantheon: Clash of Myths）

一款融合**华夏神话**、**希腊神话**与**北欧神话**的深度 **Roguelike 卡牌构筑（Deckbuilder）独立游戏**。  
专为**移动端手机竖屏**与**微信小程序环境**量身打造，支持单手触屏操作、安全区适配、全套牌强化熔炉、战术仙丹法宝与多幕史诗战役。

---

### 2. 卡牌淬火与强化锻造系统 (Card Upgrade System)
* **全卡库支持强化（`+` 阶）**：所有卡牌均可在神术熔炉中进行灵力淬火，数值全面跃升（伤害/护盾提高 35%~50%，异常层数增加，附加特殊特效）；
* **强化卡牌尊享金色动效**：卡牌拥有专属金色脉冲角标 `+`，属性词条高亮显示；
* **三大强化获取途径**：
  * **诸神圣火营地**：新增【淬炼神术】选项，免金币任选牌库中 1 张卡牌强化；
  * **诸神黑市**：商会提供【诸神铁砧】付费强化服务；
  * **神坛奇遇事件**：特定神话奇遇可触发神术顿悟。

---

### 3. 战术仙丹法宝系统 (Tactical Potions)
* **双槽位即时快捷法宝**：在战斗界面顶部常驻 2 个仙丹插槽，关键时刻扭转战局；
* **神话法宝品类**：
  * 💊 **九转金丹**：太上老君金炉神丹，立即恢复 25 点生命并获得 1 点力量；
  * 🏺 **奥林匹斯仙露**：立即恢复 2 点神力并抽 2 张牌；
  * 🍺 **狂战士神蜜酒**：本场战斗永久增加 3 点力量；
  * 🛡️ **金刚护体神液**：立即获得 20 点坚韧护盾；
  * ⚡ **雷暴天露**：造成 15 点全场雷暴伤害并施加 2 层破甲；
  * 🔥 **三昧真火灵油**：引动天地业火，给敌方全体施加 5 层灼烧。
* **掉落与获取**：战斗胜利有概率拾取，亦可在黑市商会直接购买。

---

### 4. 三大幕史诗战役长廊 (Multi-Act Campaign Progression)
不再是单调的短程小怪，游戏现在拥有完整的 3 幕史诗递进征程：
1. **第一幕 · 凡尘裂隙与古战场**
   * 普通怪：巡海夜叉、狂暴半人马、霜巨人哨兵
   * 精英怪：勒拿九头蛇 · 海德拉
   * **关底 BOSS**：**兵主 · 蚩尤战魂**（上古九黎之主，具备九黎破天斩与八肱连环杀机制）
2. **第二幕 · 泰坦圣所与诸神殿**
   * 普通怪：迷宫牛头怪 · 米诺陶洛斯、熔岩巨魔
   * 精英怪：魔狼芬里尔之嗣
   * **关底 BOSS**：**时空泰坦 · 克洛诺斯**（支配时间衰老，时间逆转蓄力与湮灭洪流）
3. **第三幕 · 世界之树与诸神黄昏**
   * 普通怪：深渊腐化巨兽
   * 精英怪：堕落女武神
   * **终极关底 BOSS**：**灭世黑龙 · 尼德霍格**（240 HP，深渊灭世龙息，击败通关）

---

### 5. 跨神话构筑 6 大成熟流派 (Archetypes)
卡牌池扩充至 **50+ 张**，支持丰富的策略流派：
* **破甲暴杀流**（杨戬 / 蚩尤战魂卡牌 / 碎空击）
* **业火灼烧流**（三昧真火 / 冥火壁 / 八卦离火阵 / 天外流星）
* **圣盾真实反伤流**（雅典娜 / 埃癸斯神盾 / 圣盾重击）
* **感电连锁雷暴流**（托尔 / 妙尔尼尔 / 锁链闪电 / 诸神黄昏）
* **狂暴卖血爆发流**（狂战嗜血 / 幽冥缚魂 / 死线血怒）
* **冥河吸血回复流**（哈迪斯 / 冥皇双叉戟 / 塔耳塔洛斯深渊）

## 📱 移动端与微信小程序适配规格

* **上下纵向对决布局**：顶部避让胶囊按钮，中场血条与法宝插槽，底部触屏手牌；
* **点选预览 + 快捷确认出牌**：杜绝小屏误操作；
