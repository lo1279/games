# 三国志·鼎立战略版 (战役对决·无限金铢版)

专为单机量身重构的 **三国战法策略卡牌对战游戏**。彻底告别繁琐的沙盘开荒铺路与漫长征兵等待，聚焦于**三国经典历史战役推演、演武通天试炼、满兵自由配将、四大战法体系与无限金铢神将抽卡**！

## 🌟 核心特色与系统

### 1. ⚔️ 双重沉浸战役 PVE 模式
- **三国历史经典战役演义 (Historical Campaigns)**：
  - **第 1 章：虎牢关之战**（迎战无双飞将吕布 + 张辽铁骑突击）
  - **第 2 章：官渡之战**（大破袁绍河北精锐暴击枪兵）
  - **第 3 章：赤壁之战**（火攻曹操南下水陆大军与夏侯惇反伤反击）
  - **第 4 章：夷陵之战**（破解陆逊周瑜大都督烈火连营体系）
  - **第 5 章：洛阳问鼎天下**（决战终极大魏与群雄至尊阵容）
  - 拥有 1~3 星通关评分机制。
- **演武通天试炼阁 (Trials)**：
  - 阶梯式天梯关卡爬塔，挑战由浅入深的经典三战顶配阵容（黄巾队、都督弓、桃园盾、魏法骑、麒麟弓等）。

### 2. 🛡️ 零负担极致配将体验
- **统御 Cost 限制全解禁 (上限 21)**：可随心搭配任意 3 名顶级五星神将。
- **满兵标准出战**：每位武将默认以 10,000 满编兵力出战，战后无需等待征兵补员，随时即开即打。
- **四大兵种自由切换**：骑兵、盾兵、弓兵、枪兵，严格遵循循环克制关系（骑克盾、盾克弓、弓克枪、枪克骑），克制方增伤 15% 并受击减免！
- **阵营国家队加成**：上阵 3 名同阵营武将激活 10% 全属性飞升！

### 3. 🎴 四大战法全解锁配装
- 涵盖 **指挥、被动、主动(蓄力机制)、突击** 四大体系。
- 盛气凌敌（封突击）、八门金锁阵（先攻+群体减伤）、所向披靡（毁灭兵刃轰击）、刮骨疗毒（解控急救）、一身是胆（洞察免控）全套已解锁，点击武将卡自由搭配！

### 4. 🏮 拜将台无限金铢爽抽
- 内置 GM 无限金铢特权，金铢始终充盈 999,999，20 抽必出五星硬保底，轻松抽齐魏蜀吴群全部神将！
