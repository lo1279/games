# 雷霆战机 (Thunder Fighter) · 微信小程序与移动全屏重制版

一款基于 **HTML5 Canvas 2D + Web Audio API** 纯原生现代技术打造的高画质街机纵版射击游戏。

项目专为**手机移动端、微信内置浏览器与微信小程序**进行了深度架构优化，同时完美兼容 PC 桌面端键鼠微操。

---

## 🎮 快速开始游玩

### 1. 本地启动
- **直接启动**：双击根目录下的 `index.html`，通过任意现代浏览器（Chrome、Edge、Safari 等）即可全屏畅玩！
- **静态服务器模式**：
  ```bash
  npx serve .
  # 或
  python -m http.server 8080
  ```
  在手机浏览器中输入本机 IP 地址即可真机全屏游玩。

### 2. 微信小程序部署
项目根目录下附带完整的微信小程序工程：`wechat-miniprogram/`
- 在**微信开发者工具**中点击“导入项目”，选择 `wechat-miniprogram/` 目录；
- 支持真机预览、横竖屏自适应及全屏沉浸式体验（详细说明请参阅 `wechat-miniprogram/README-MINIPROGRAM.md`）。

## 🚀 养成、道具与战斗机制

- **P (Power Up)**：强化武器主炮阶梯（单兵双联 ➔ 四重连发 ➔ 僚机三向 ➔ 贯穿激光+飞弹 ➔ 触发暴走）。
- **S (Shield Repair)**：修复战机偏折护盾（优先吸收伤害，护盾破损后才会消耗机体生命）。
- **B (Thunder Bomb)**：补充 1 枚雷霆 EMP 核弹储备（上限 5 枚），释放时清除全屏普通弹幕并**强制过载切断 Boss 激光**。
- **★ (Crystal)**：能量水晶，靠近时磁吸（暴走状态全屏吸附），享受 Combo 连击加成并同步刷新最高纪录！

## 📱 移动端与微信环境深度优化技术指标

1. **防橡皮筋下拉露底与全屏手势安全**：
   - 注入 `overscroll-behavior: none`、`position: fixed`，结合原生手势拦截，杜绝 iOS Safari / 微信下拉回弹与双指误缩放。
2. **iOS / 微信音频自愈引擎**：
   - 适配微信 `WeixinJSBridgeReady` 与页面 `visibilitychange` 生命周期，接电话或切后台返回游戏时自动唤醒并重连 Web Audio 上下文。
3. **视口与 Retina 动态自适应**：
   - 联动 `window.visualViewport` 精准避让 iPhone 灵动岛、刘海屏与底部 Home 横条；
   - DPR 智能夹逼在 1.5 ~ 2.0，兼顾 Retina 极致高清画质与千元机省电防发热。
