# 雷霆战机 (Thunder Fighter)

一款基于 HTML5 Canvas 2D + Web Audio API 纯原生技术打造的经典太空科幻纵版飞行射击街机游戏。

---

## 🎮 快速开始游玩

1. **直接启动**：
   - 方式一：直接在文件管理器中双击打开 `index.html`，通过任意现代浏览器（Chrome、Edge、Firefox 等）即可直接畅玩！
   - 方式二：在本项目根目录运行任意静态服务器，例如：
     ```bash
     npx serve .
     # 或
     python -m http.server 8080
     ```
     然后访问 `http://localhost:8080`。

2. **操作说明**：
   - **移动**：
     - **鼠标模式**：在画面上移动/滑动鼠标，战机将自动平滑对准跟随。
     - **键盘模式**：`W` `A` `S` `D` 或 `↑` `↓` `←` `→` 方向键控制战机机动。
     - **触控模式**：手机或平板屏幕上按住滑动即可。
   - **射击**：战机默认处于**全自动高速开火**状态，无需疲劳连击按键；亦可按住 `空格键 (Space)` 强制射击。
   - **必杀核弹**：按 `B` 键或点击屏幕右下角的 **释放核弹** 按钮，施展全屏雷霆 EMP 脉冲，瞬间瓦解所有敌机弹幕并造成毁灭性打击。
   - **暂停**：按 `P` 键暂停/继续游戏。
   - **音效切换**：点击左下角 **音效** 按钮可一键静音或开启音效。

## 🚀 核心战斗机制

### 1. 战机升级与暴走状态 (Berserk Mode)
- **LV1 单兵脉冲**：双联装疾速等离子弹。
- **LV2 高能连发**：四重密集高能弹。
- **LV3 扇形扩散**：三向扇形散射 + 侧翼双僚机伴飞协同开火。
- **LV4 强袭穿透**：高能贯穿激光束 + 僚机双光束 + 扇形弹 + 微型制导追踪导弹。
- **LV5 极度暴走 (MAX RAGE)**：
  - 拾取大量水晶能量充盈或武器升至顶级即可激活**超能暴走状态**！
  - 射速与弹幕翻倍，极光加特林光束 + 追踪导弹雨全屏覆盖，吸附全场水晶！

### 2. 战利品掉落 (Drops & Power-ups)
- **P (Power Up)**：强化战机武器等级，满级直接触发暴走。
- **S (Shield)**：修复战机能量护盾（优先抵御敌方伤害，护盾消耗完毕才会损伤机体生命）。
- **B (Thunder Bomb)**：补充 1 枚雷霆 EMP 核弹储备（最高上限 5 枚）。
- **★ (Crystal)**：能量水晶，靠近时自动产生磁性吸附，增加战功积分并为暴走充能。

### 3. 敌机编队与史诗 Boss
- **突击蜂 (ScoutFighter)**：高速俯冲与正弦机动，成群突袭。
- **巡航舰 (Cruiser)**：中型装甲，高空悬停并倾泻扇形阻截弹。
- **重型装甲炮艇 (Gunship)**：坚厚装甲，周期性发射自机狙和双向螺旋弹。
- **极速自杀机 (Kamikaze)**：危险瞄准后超音速冲撞。
- **终结者母舰 (Titan-Dreadnought Boss)**：
  - **Phase 1**：巡航移动，双翼齐射螺旋花瓣弹幕。
  - **Phase 2**：展开装甲裸露核心，蓄力发射通天贯地的高能粗激光主炮！
  - **Phase 3 (狂暴形态)**：机体赤红过载，高速万花筒 360 度连发弹幕，极具挑战性！

## 🛠️ 技术架构亮点
- **零依赖运行**：纯原生 HTML5 / ES6 / CSS3 开发，无需 npm 庞大构建即可运行。
- **Web Audio API 纯代码拟真音效**：动态振荡器实时调频合成激光、导弹、爆炸音效，杜绝外部静态音频加载失败与延迟。
- **高性能粒子引擎**：支持引擎尾焰、受击火花、多级冲击波环与屏幕剧烈震颤反馈。
- **多层视差星空系统**：三层太空纵深群星与星云流光，呈现深邃宇宙沉浸感。
