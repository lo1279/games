# 雷霆战机 · 微信小程序部署与运行指南

本项目已完成 100% 手机端全屏自适应与触控手感适配，并提供标准的微信小程序接入工程。

---

## 🚀 方式一：本地开发与真机调试（无需购买服务器）

### 第 1 步：启动本地游戏静态服务
在游戏主目录 `D:\ai项目\games\thunder-fighter\` 启动一个 HTTP 静态服务器：
```bash
cd "D:\ai项目\games\thunder-fighter"
python -m http.server 8080
```
或使用 Node.js：
```bash
npx serve -p 8080 .
```

### 第 2 步：查看您电脑的局域网 IP
在命令行输入：
```powershell
ipconfig
```
找到 `IPv4 地址`（例如：`192.168.1.8`）。

### 第 3 步：修改小程序中的目标地址
打开 `wechat-miniprogram/pages/index/index.js`，将 `gameUrl` 改为您电脑的局域网 IP：
```javascript
data: {
  gameUrl: 'http://192.168.1.8:8080/index.html' // 改为您的局域网IP
}
```

### 第 4 步：导入微信开发者工具
1. 打开 **微信开发者工具**（WeChat DevTools）。
2. 点击 **导入项目**。
3. **目录**选择：`D:\ai项目\games\thunder-fighter\wechat-miniprogram\`。
4. **AppID**：可选择自己的小程序测试号或填入正式 AppID。
5. 进入工具后，点击右上角 **【详情】** -> **【本地设置】** -> 勾选 **【不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书】**。
6. 点击上方 **【真机调试】** 或 **【预览】**，微信扫码即可在手机微信中全屏畅玩！

## 🌐 方式二：正式发布上线（免费/一键托管方案）

当准备正式发布到微信线上时，需要将前端文件放置在一个支持 HTTPS 的托管地址：

### 推荐方案 A：微信官方「腾讯云开发 (CloudBase)」静态网站托管（最推荐·免备案）
1. 在微信开发者工具中，开通 **云开发**。
2. 进入云开发控制台 -> 点击 **静态网站托管**。
3. 将 `D:\ai项目\games\thunder-fighter\` 下的所有前端文件（`index.html`、`style.css`、`js/` 文件夹等）直接拖拽上传。
4. 上传完成后获得一个专属的安全 HTTPS 链接（如 `https://xxxx.tcloudbaseapp.com/index.html`）。
5. 微信对自己的云开发域名**免配置业务域名白名单**，在小程序后台直接可用！将该链接填入 `pages/index/index.js` 的 `gameUrl` 即可直接提交审核发布！

### 推荐方案 B：个人服务器 / 腾讯云 / 阿里云 / Vercel
1. 将前端文件上传至您的 HTTPS 域名服务器。
2. 登录 [微信公众平台 (mp.weixin.qq.com)](https://mp.weixin.qq.com)。
3. 进入 **【开发管理】** -> **【开发设置】** -> **【业务域名】**。
4. 添加您的服务器域名（需下载校验文件放置在服务器根目录）。
5. 在 `pages/index/index.js` 中将 `gameUrl` 替换为该线上地址即可。
