# 🎮 综合游戏大厅 (Game Hub Arcade)

一个专为本地 Web 游戏打造的聚合游戏大厅，采用现代暗黑赛博与玻璃拟态（Glassmorphism）电竞设计，将 7 款精选前端独立游戏无缝集成，开箱即玩。

---

## 🌟 游戏大厅核心特性

1. **集中聚合与沉浸游玩**：
   - **大厅剧场模式 (Arcade Theater)**：直接在大厅内全屏沉浸畅玩，支持全屏切换、即时重新开始、操作指南快捷查看与 Esc 一键返回大厅，无需来回切换页面；
   - **独立标签页模式 (New Tab)**：支持一键在独立浏览器标签页运行任意游戏。
2. **分类与即时检索**：
   - 支持按 **全部**、**休闲益智**、**策略卡牌**、**动作射击**、**街机复古** 以及 **我的收藏** 快速分类筛选；
   - 支持实时模糊搜索（支持中英文游戏名、玩法标签与核心特色搜索）；
   - 支持按推荐、游玩热度、最近游玩时间、名称排序。
3. **本地状态持久化 (LocalStorage)**：
   - 自动记录每款游戏的游玩次数与上次游玩时间；
   - 支持一键收藏（爱心）游戏并在专属收藏标签页展示。
4. **0 依赖 Windows 原生一键启动与智能防端口冲突**：
   - 内置 `launch_hall.bat` 批处理，无需安装 Node.js 或 Python 环境；
   - 具备 **智能自动端口探测 (Auto Port Hunting)**：从 `8080` 开始检测，如遇外部软件占用自动顺延至 `8081`~`8099` 可用端口，彻底避免端口冲突；
   - 亦完全支持双击 `index.html` 离线直接运行。

## 🚀 启动与游玩方式

### 方式 1：一键批处理启动 (推荐)
直接双击根目录下的 **`launch_hall.bat`**。
系统将自动启动轻量本地服务器并呼出您的默认浏览器进入游戏大厅。

### 方式 2：直接双击 HTML
直接双击根目录下的 **`index.html`** 即可在任意现代浏览器（Chrome、Edge 等）中运行。
