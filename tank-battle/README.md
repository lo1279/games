# 坦克大战 (Battle City / Tank Battle) - HTML5 Canvas 经典重制版

一款高度还原任天堂经典红白机（FC/NES）《坦克大战》核心手感与玩法机制的现代原生网页游戏，采用纯原生 **HTML5 Canvas + 面向对象 JavaScript + Web Audio API** 构建，零外部依赖，极速秒开！

---

## 🎮 快速开始运行

### 方法 1：直接双击打开
直接在资源管理器中进入 `D:\ai项目\games\tank-battle` 目录，双击 **`index.html`** 即可在任意现代浏览器（Chrome、Edge、Firefox 等）中畅玩！

### 方法 2：使用轻量本地服务器（推荐）
在命令行中进入该目录运行：
```bash
# 使用 Python 启动
cd D:\ai项目\games\tank-battle
python -m http.server 8080
```
或使用 Node.js：
```bash
npx serve .
```
然后在浏览器中访问 `http://localhost:8080` 即可。

## 💥 核心系统与战斗特性

### 1. 玩家坦克 4 阶升级演进
- **Lv1 新兵坦克**：基础车速与弹速，单发炮弹。
- **Lv2 疾风坦克**：大幅提升炮弹飞行速度，先发制人。
- **Lv3 重炮坦克**：允许场上同时连发 2 发炮弹。
- **Lv4 终极破钢坦克**：重装装甲，不仅拥有双连发，炮弹还可**直接击碎坚硬的铁墙（Steel）**！

### 2. 战场地形机制
- 🧱 **砖墙 (Brick)**：支持经典的**微四分格破坏**判定，子弹打到哪里就削掉哪里的砖层，可精准打穿单行通道。
- ⛓️ **铁墙 (Steel)**：坚不可摧，普通炮弹命中会发出清脆的金属撞击声弹开，仅 Lv4 玩家炮弹可粉碎。
- 🌊 **水面 (Water)**：流动水域，坦克无法通行，但炮弹可以畅行无阻。
- 🌿 **丛林草丛 (Grass)**：高层掩体，坦克驶入会被树叶遮挡，适合伏击敌军。
- ❄️ **冰面 (Ice)**：地面光滑，坦克行驶平顺。
- 🦅 **老鹰基地 (Base)**：玩家守卫的核心！若被敌军炮弹摧毁，老鹰变为废墟残骸并宣告失败。

### 3. 敌军 4 大主力装甲
- **普通装甲车**：1 点生命，常规速度与伤害。
- **轻型极速车**：1 点生命，机动速度极快，擅长游击包抄。
- **强击火炮车**：1 点生命，发射超高速破甲炮弹。
- **重型装甲车**：高达 4 点生命值，每次承受炮火都会变换外观颜色（绿 $\rightarrow$ 橙 $\rightarrow$ 红 $\rightarrow$ 金）。
- **闪烁奖励车**：车身红白高频闪烁，消灭后必在地图空地上掉落经典道具！

### 4. 经典全套道具
- ⭐ **五角星**：提升玩家战车等级 1 级。
- 💣 **全屏炸弹**：瞬间引爆全场当前所有敌军坦克，斩获高额积分。
- ⏰ **定时闹钟**：彻底冻结场上所有敌军坦克行动与开火 10 秒。
- ⛏️ **铁壁铁铲**：将基地老鹰周围一圈脆弱砖墙瞬间加固为铁墙（持续15秒，最后3秒闪烁警示）。
- 🛡️ **金钟罩钢盔**：赋予玩家坦克 10 秒无敌光环护盾。
- 💖 **奖命小坦克**：为玩家增加 1 条宝贵生命。

## 📁 目录文件结构

```
D:\ai项目\games\tank-battle\
│
├── index.html              # 游戏 HTML5 页面与 UI 控件
├── style.css               # 街机复古外壳、CRT 滤镜与 HUD 样式
├── README.md               # 游戏玩法与特性说明文档
│
└── js/
    ├── config.js           # 游戏参数、尺寸、调色板与常量
    ├── audio.js            # Web Audio API 纯程序合成 8-bit 复古音效
    ├── levels.js           # 关卡地图与 20 辆敌军波次配置
    ├── map.js              # 地图瓦片渲染、四分微砖破坏与基地老鹰状态
    ├── bullet.js           # 炮弹飞行、边界与对撞湮灭物理判定
    ├── explosion.js        # 经典同心圆爆燃与飞溅残骸粒子特效
    ├── tank.js             # 坦克基类、网格平滑转向与履带动画
    ├── player.js           # 玩家坦克 4 级形态进化与护盾控制
    ├── enemy.js            # 4 类敌军坦克 AI 寻路、巡逻与射击决策
    ├── powerup.js          # 道具生成、闪烁动效与拾取增益
    └── game.js             # 游戏总控、状态机与碰撞处理 GameLoop
```
