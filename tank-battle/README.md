# 坦克大战 (Battle City / Tank Battle) - HTML5 Canvas 经典重制版

一款高度还原任天堂经典红白机（FC/NES）《坦克大战》核心手感与玩法机制的现代原生网页游戏，采用纯原生 **HTML5 Canvas + 面向对象 JavaScript + Web Audio API** 构建，零外部依赖，极速秒开！

全面深度适配**桌面电脑、手机移动端浏览器与微信小程序 / 小游戏环境**，支持键盘与触摸双模控制、多形态自适应布局。

---

## 🎮 快速开始运行

### 方法 1：直接双击打开
在资源管理器中进入 `D:\ai项目\games\tank-battle` 目录，双击 **`index.html`** 即可在任意现代浏览器（Chrome、Edge、Safari、Firefox 等）中即开即玩！

### 方法 2：使用轻量本地服务器
在命令行中进入该目录运行：
```bash
# 使用 Python 启动
cd D:\ai项目\games\tank-battle
python -m http.server 8080
```
或使用 Node.js：
```bash
npx serve .
```
然后在浏览器中访问 `http://localhost:8080` 即可。

## 🕹️ 双模操作指南

### 1. 桌面端键盘操作

| 操作 | 键位 | 说明 |
| :--- | :--- | :--- |
| **移动控制** | `W` / `A` / `S` / `D` 或 `↑` `←` `↓` `→` | 控制坦克上、左、下、右移动（自带网格平滑对齐拐弯辅助） |
| **开火射击** | `J` 键 / `空格键 (Space)` / `K` 键 | 发射炮弹（支持炮弹在空中精准互碰抵消） |
| **暂停 / 继续** | `P` 键 | 暂停或继续当前激烈战局 |
| **静音切换** | `M` 键 | 切换 8-bit 复古合成音效开/关 |
| **重新开始** | `R` 键 / `Enter` 键 | 在标题界面或结算/失败界面快速重新出击 |

### 2. 📱 移动端与微信触控操作

- **虚拟十字方向盘 (D-Pad)**：支持滑动摇杆手感，手指滑出外圈亦有防脱轨机制，转向丝滑顺畅。
- **A 键（红宝石按钮）**：点按开火发射炮弹。
- **B 键（琥珀橙按钮）**：长按全自动高速连发，火力压制。
- **系统快捷键**：手柄中央集成一键暂停、重新开始与静音切换。

## 📱 移动端与微信环境深度优化

1. **视口与安全区域弹性适配（彻底杜绝滚动条）**
   - 采用 `100dvh` 彻底约束页面视口，全面引入 `env(safe-area-inset-top)` 与 `env(safe-area-inset-bottom)` 避让刘海屏与系统手势横条。
   - 战场画布采用 `max-width: min(94vw, calc(100dvh - 245px), 400px)` 弹性收缩计算，在各类紧凑屏幕（如 iPhone SE 375x667）下也能保持整机一屏内显示，**无任何纵向与横向滚动条**。

2. **🕹️ 横屏掌机沉浸模式 (Landscape Handheld Mode)**
   - 手机横屏时自动进入掌机分体布局：
     - **左侧**：大尺寸复古十字方向键；
     - **中央**：全高正方形无黑边像素战场；
     - **右侧**：双开火按键（上 A 键普通开火，下 B 键连发）。
   - 完美重现 Game Boy / GBA 等经典掌机握持手感。

3. **触控滑动与断触保护**
   - 十字盘 `touchmove` / `touchend` 绑定至全局 `window` 并通过 `identifier` 绑定指尖，避免手指滑出圆形面板边缘导致坦克卡死。
   - 集成 **Screen Wake Lock API**，激烈交火过程中自动保持屏幕常亮防息屏。

4. **微信小程序与切后台音频自动复活**
   - 深度监听微信专有 `WeixinJSBridgeReady` 事件，进入小程序第一时间自动激活音频上下文；
   - 监听 `visibilitychange` 与 `pageshow`，玩家切后台回复微信再返回时，自动执行 `AudioContext.resume()`，彻底解决移动端切后台后游戏静音的顽疾。

## 💥 核心系统与战斗特性

### 1. 玩家坦克 4 阶升级演进（通关继承）
- **Lv1 新兵坦克**：基础车速与弹速，单发炮弹。
- **Lv2 疾风坦克**：大幅提升炮弹飞行速度，先发制人。
- **Lv3 重炮坦克**：允许场上同时连发 2 发炮弹。
- **Lv4 终极破钢坦克**：重装装甲，双连发高弹速，且炮弹可**直接击碎坚硬铁墙（Steel）**！
- 🌟 **形态继承**：关卡结算进入下一关时，完整保留玩家当前的强化等级与破钢能力。

### 2. 战场地形机制
- 🧱 **砖墙 (Brick)**：支持经典的**微四分格破坏**判定，子弹打到哪里就削掉哪里的砖层，可精准打穿单行通道。
- ⛓️ **铁墙 (Steel)**：坚不可摧，普通炮弹命中发出清脆金属反弹声，仅 Lv4 玩家炮弹可粉碎。
- 🌊 **水面 (Water)**：流动水域，坦克无法通行，但炮弹可以畅行无阻。
- 🌿 **丛林草丛 (Grass)**：高层掩体，坦克驶入会被树叶遮挡，适合伏击敌军。
- ❄️ **冰面 (Ice)**：地面光滑，坦克行驶平顺。
- 🦅 **老鹰基地 (Base)**：玩家守卫的核心！若被敌军摧毁，老鹰变为废墟残骸并宣告 Game Over。

### 3. 敌军 4 大主力装甲与智能火力网
- **普通装甲车**：1 点生命，常规速度与伤害。
- **轻型极速车**：1 点生命，机动速度极快，擅长游击包抄。
- **强击火炮车**：1 点生命，发射超高速破甲炮弹。
- **重型装甲车**：高达 4 点生命值，每次承受炮火都会变换外观颜色（绿 $\rightarrow$ 橙 $\rightarrow$ 红 $\rightarrow$ 金）。
- **闪烁奖励车**：车身红白高频闪烁，消灭后必在地图空地上掉落经典道具！
- **持续火力机制**：实时回收子弹配额，敌军持续保持压迫性开火与战术反应。

### 4. 碰撞物理反馈与近战杀敌
- **钢铁火花与触觉反馈**：敌我坦克相撞时，接触边缘迸发金属火花粒子、播放清脆钢铁碰撞音效并触发手机微震动。
- **金钟罩护盾碾压杀敌**：玩家处于无敌护盾状态时，**直接撞击即可碾碎敌方坦克**并斩获击毁得分！

### 5. 经典全套道具
- ⭐ **五角星**：提升玩家战车等级 1 级。
- 💣 **全屏炸弹**：瞬间引爆全场当前所有敌军坦克，斩获高额积分。
- ⏰ **定时闹钟**：彻底冻结场上所有敌军坦克行动与开火 10 秒。
- ⛏️ **铁壁铁铲**：将基地老鹰周围一圈脆弱砖墙瞬间加固为铁墙（持续 15 秒，最后 3 秒闪烁警示）。
- 🛡️ **金钟罩钢盔**：赋予玩家坦克 10 秒无敌光环护盾。
- 💖 **奖命小坦克**：为玩家增加 1 条宝贵生命。
