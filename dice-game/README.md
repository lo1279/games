# 🎲 3D 骰王争霸 (Dice Master 3D)

一款兼具拟真 3D 物理交互与丰富趣味玩法的现代化掷骰子游戏，纯前端构建，开箱即玩。

---

## 🌟 游戏特色

1. **真实 3D 物理渲染**：基于 Three.js 定制开发的 3D 骰子动力学引擎，支持立体旋转、自由落体、真实台面碰撞与弹跳。
2. **拟真程序化音效**：基于 Web Audio API 实时合成摇骰盅、骰子碰撞木质台面、筹码入袋及胜利欢呼音效，无需下载外部音频资源，秒开即响。
3. **四合一丰富玩法**：
   - 🎯 **骰宝押大小 (Sic Bo)**：经典娱乐玩法，支持大小、单双、总点数、全围豹子高倍率下注，配备开奖走势路单。
   - 🗣️ **吹牛大话骰 (Liar's Dice)**：经典聚会酒吧玩法，玩家与 AI 各持 5 颗暗骰，支持万能 1 点规则与心理博弈。
   - ⛵ **快艇骰子 (Yahtzee)**：经典策略益智计分，每轮可重掷 3 次并任意锁定骰子，挑战 13 项组合极限高分与满 63 红利。
   - 🎲 **自由随心掷骰 (Free Roll)**：支持 1~6 颗骰子自由投掷与总和极值分析，聚会/决议/桌游随手利器。
4. **筹码与救济机制**：初始赠送 1,000 筹码，输光时支持一键领取破产救济金 500 筹码，进度自动保存到浏览器本地 (LocalStorage)。

## 🚀 启动与运行

本游戏为纯静态 Web 架构，支持以下任意方式启动：

### 方式 1：双击直接运行 (最快捷)
直接在文件资源管理器中打开当前目录，双击 `index.html` 即可在任意现代浏览器（Chrome、Edge 等）中畅玩。

### 方式 2：使用本地 HTTP 服务
如果希望使用静态服务器运行，可在当前目录打开终端执行：
```bash
# 使用 Python 启动
python -m http.server 8080

# 或使用 Node.js / npx
npx serve .
```
然后在浏览器访问 `http://localhost:8080` 即可。
