# 🎮 经典俄罗斯方块 (Tetris Neon Edition)

一款基于原生 HTML5 + Canvas + Web Audio API 打造的现代化、赛博霓虹风格的经典俄罗斯方块游戏。

---

## ✨ 核心特性

- **零环境依赖，双击即玩**：无需安装 Node.js、Python 或任何打包工具，双击 `index.html` 即可在 Edge、Chrome 等任意现代浏览器中运行。
- **经典 7-Bag 随机机制**：保证每轮随机生成的 7 种方块（I, J, L, O, S, T, Z）分布均匀，绝不连续卡手。
- **标准 SRS 踢墙旋转系统 (Super Rotation System)**：支持贴墙、狭缝旋转穿透，手感顺滑。
- **幽灵投影 (Ghost Piece)**：半透明虚线落点预判，助您快速精准放置。
- **暂存机制 (Hold)**：支持将当前方块暂存备用（每回合仅限一次）。
- **动感粒子与消行动画**：消行时触发爆散高光微粒子与行闪烁动效。
- **纯原生算法合成音效 (Web Audio API)**：内置合成器即时生成移动、旋转、消行、升级、GameOver 音效，无音频外部缺失风险，支持一键静音。
- **双端自适应与虚拟按键**：同时支持桌面端键盘操作与触屏设备虚拟操作面板。
- **本地高分持久化**：自动通过 `localStorage` 保存并记录您的历史最高得分。

## 🕹️ 操作说明

### 键盘快捷键 (桌面端)
| 按键 | 功能说明 |
| :--- | :--- |
| **`←`** 或 **`A`** | 向左移动方块 |
| **`→`** 或 **`D`** | 向右移动方块 |
| **`↑`** 或 **`W`** | 顺时针旋转方块 (支持 SRS 踢墙) |
| **`↓`** 或 **`S`** | 软降加速 (轻触向下) |
| **`Space` (空格)** | **硬降** (直接瞬降到底并锁定) |
| **`C`** 或 **`Shift`** | **暂存方块 (Hold)** |
| **`P`** 或 **`Esc`** | 暂停 / 继续游戏 |

### 触控按键 (移动端 / 平板)
屏幕下方提供虚拟按键：**暂存**、**旋转**、**瞬降**、**左移**、**下落**、**右移**。

## 📂 项目结构

```text
D:\ai项目\games\tetris\
├── index.html         # 游戏主页面
├── style.css          # 霓虹/赛博朋克玻璃拟态视觉样式
├── game.bundle.js     # 独立自包含免跨域运行脚本 (推荐直接使用)
├── README.md          # 项目说明文档
└── js/                # 模块化源码 (便于代码阅读与二次开发)
    ├── constants.js   # 形状矩阵、颜色、SRS 踢墙偏移表、难度配置
    ├── audio.js       # 基于 Web Audio API 的算法音效引擎
    ├── piece.js       # 方块类与 7-Bag 随机发牌算法
    ├── board.js       # 网格底板逻辑、碰撞检测与 Canvas 渲染器
    └── game.js        # 游戏主循环、得分规则与事件驱动中心
```
