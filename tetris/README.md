# 🎮 经典俄罗斯方块 (Tetris Neon Edition)

一款基于原生 **HTML5 Canvas + Web Audio API + CSS3 赛博霓虹视觉** 打造的现代化全平台俄罗斯方块游戏。深度支持 PC 桌面端、智能手机端触控操作与微信小程序（`<web-view>`）沉浸式运行。

---

## ✨ 核心特性

- **零环境依赖，双击即玩**：无需安装 Node.js、Python 或任何构建工具，直接双击 `index.html` 即可在 Edge、Chrome、Safari 等现代浏览器中顺畅运行。
- **全平台自适应与沉浸体验**：
  - **PC 桌面端**：经典键盘操作，自适应居中窗口与炫光光晕。
  - **手机移动端**：适配 `100dvh` 与安全区（Safe Area），彻底根除微信与 iOS 橡皮筋回弹露白，支持全面屏触控手势与虚拟手柄。
  - **微信小程序无缝嵌入**：内置完整配套的小程序模板（`weapp-webview/`），支持扫码预览与生产环境发布。
- **经典 7-Bag 随机机制**：保证每轮发牌的 7 种经典方块（I, J, L, O, S, T, Z）分布均匀，绝不连续卡手。
- **标准 SRS 踢墙旋转系统 (Super Rotation System)**：支持贴墙、狭缝旋转穿透，手感顺滑。
- **幽灵投影 (Ghost Piece)**：半透明虚线落点预判，助您快速精准定点摆放。
- **暂存机制 (Hold)**：支持将当前方块暂存备用（每回合仅限一次），内置堆顶防穿模防夹保护。
- **动感粒子与消行动画**：消行时触发爆散高光微粒子、行爆闪动效及屏幕微震动。
- **纯原生算法合成音效 (Web Audio API)**：内置合成器即时生成移动、旋转、消行、升级、GameOver 音效，无音频外部缺失风险，并在移动端和微信环境做了首触自动解锁兼容。
- **本地高分持久化**：自动通过 `localStorage` 保存并记录您的历史最高得分。

## 🦎 全新核心玩法：【变色龙变异方块】(Morphing Piece)

为了提升策略趣味性与随机刺激感，游戏引入了创新的“变色龙变异方块”系统：

1. **变异概率与发牌规则**：
   - 每轮发牌时拥有 **15%** 的概率生成稀有的“变色龙变异方块”；
   - **四行连消彩蛋（Tetris Bonus）**：只要玩家单次消除 4 行（Tetris!），下一轮的下一个方块**必定奖励产出**一个变异方块！
2. **空中动态变形与防卡模保护**：
   - 变异方块在下落过程中**每隔 1.4 秒自动随机变换一次形状**；
   - **智能碰撞容错探测**：在变形瞬间利用微调偏移表检测周围空间，若局部空间狭小则自动微调或顺延下一种合适形状，绝不会卡墙或卡死在已有方块堆中。
3. **绚丽视听与触感反馈**：
   - **彩虹流光呼吸质感**：变异方块呈现动态 HSL 彩虹流光色彩；
   - **变形脉冲粒子**：变换瞬间向外爆散出一圈绚丽的彩虹微粒子；
   - **专属音效与触感**：变形时伴随专属升频科技滑音 (`playMorph`) 与移动端震动反馈；
   - **看板专属角标**：在 NEXT 预览框与 HOLD 暂存框中拥有醒目的 `★MORPH` 发光角标。

## 📈 难度递增与计分机制

游戏采用经典平滑而紧张的阶梯式难度递增曲线，随着消除行数增加，方块下落速度呈指数级加快。

### 1. 等级提升规则
- **初始等级**：Level 1
- **升级判定**：每消除 10 行提升 1 级，公式：`Level = Math.min(20, Math.floor(lines / 10) + 1)`
- **最高等级**：Level 20

### 3. 得分奖励体系
得分基础分随着当前等级 (`Level`) 成倍放大：
- **单行消除 (Single)**：`100 × Level` 分
- **双行消除 (Double)**：`300 × Level` 分
- **三行消除 (Triple)**：`500 × Level` 分
- **四行连消 (Tetris!)**：`800 × Level` 分（同时触发变色龙变异方块彩蛋）
- **软降 (Soft Drop)**：每成功加速下落 1 格 `+1` 分
- **硬降 (Hard Drop)**：每瞬降 1 格 `+2` 分

## 🕹️ 游戏操作指南

### 1. 桌面电脑端 (键盘操作)
| 按键 | 功能说明 |
| :--- | :--- |
| **`←`** 或 **`A`** | 向左移动一格 |
| **`→`** 或 **`D`** | 向右移动一格 |
| **`↑`** 或 **`W`** | 顺时针旋转方块 (支持 SRS 踢墙穿透) |
| **`↓`** 或 **`S`** | 加速软降 (按住快速向下推进) |
| **`Space` (空格键)** | **硬降** (直接瞬间坠落到底部并锁定) |
| **`C`** 或 **`Shift`** | **暂存当前方块 (Hold)** |
| **`P`** 或 **`Esc`** | 暂停 / 继续游戏 |

### 2. 智能手机端 (触控手势 + 虚拟手柄双模)

#### 屏幕手势操作
- **左右滑动**：手指在游戏区域左右轻划，基于步长精准平移方块；
- **轻触点击**：轻点画布任意位置，顺时针旋转方块；
- **向下划动**：顺畅下划加速软降；
- **双击屏幕**：快速连续双击画布，立即执行硬降（瞬降到底）。

#### 虚拟手柄操作
- **左手控制区**：`◀ 左移`、`▼ 下落`、`▶ 右移`（支持长按自动连续位移 DAS/ARR：长按 180ms 后以 50ms 频率快速连发）；
- **右手控制区**：`暂存`、`旋转 ↻`、`瞬降 ⤓`。
- **触感反馈**：调用原生短震动 `vibrateShort`，每一次移动、旋转与消行带来爽快打击感。

## 🚀 运行与部署指南

### 1. 本地直接游玩 (最简方式)
在文件管理器中找到 `index.html`，**直接双击打开**，即可在电脑默认浏览器中立即开始游玩。

### 2. 手机局域网与线上托管部署
将根目录下的静态资源（`index.html`、`style.css`、`game.bundle.js`）部署到任意静态 Web 服务器：
- **静态托管推荐**：GitHub Pages、Vercel、Cloudflare Pages、腾讯云 CloudBase。
- **局域网体验**：使用 VS Code 的 `Live Server` 插件，手机连接同一 Wi-Fi 后通过电脑局域网 IP 即可访问。

### 3. 部署为微信小程序
1. 参考 `weapp-webview/README_WECHAT.md`；
2. 打开**微信开发者工具**，导入 `weapp-webview/` 目录；
3. 将 `pages/index/index.js` 中的 `gameUrl` 替换为您线上部署的 HTTPS 链接；
4. 勾选开发工具中的“不校验合法域名”，即可在开发者工具模拟器运行或生成二维码扫码在手机微信真机中畅玩！
